💡 Distrofias — Duchenne vs Becker

Duchenne = Deleción (sin distrofina) → inicio ~3-5a, pseudohipertrofia, Gowers+, CPK ↑↑↑

Becker = Benigna (distrofina anormal) → inicio tardío, progresión lenta, CPK ↑

Ambas ligadas a X. Duchenne: silla de ruedas ~12a, muerte ~20-30a. Becker: ambulatorio >16a.

💡 Miastenia Gravis vs Lambert-Eaton

Miastenia = Mejora con descanso, empeora con actividad → anti-AChR (post) → timoma

Lambert = Mejora con actividad repetida → anti-VGCC (pre) → SCLC

Edrofonio mejora MG pero no LE. MG: ptosis, diplopía primero. LE: extremidades proximales primero.

💡 Glucogenopatías — "Very Poor Carbohydrate Metabolism"

Von Gierke (I): G6Pasa, hígado ↑, hipoglicemia | Pompe (II): α-glucosidasa, corazón ↑↑

Cori (III): desramificante, hígado | McArdle (V): fosforilasa muscular, calambres + mioglobinuria

⚡ Integración clave — Contracción muscular en 4 niveles
  • Histología: Sarcómero → líneas Z, bandas A/I, zona H → filamentos gruesos/delgados
  • Bioquímica: Ca²⁺ → troponina C → conformación → ciclo ATPasa miosina → ATP para desacople
  • Fisiología: Unidad motora → PA → Ca²⁺ del RS → acoplamiento E-C → sumación → curvas L-T y F-V
  • Patología: Sin distrofina → daño sarcolema → ↑CPK → necrosis → distrofia. Anti-AChR → falla transmisión → miastenia

Crear un mapa conceptual que conecte los 4 niveles. Este es el mejor simulacro para el NBME.

💡 Músculo Liso vs Estriado — Contracción

Liso: Ca²⁺ + Calmodulina → MLCK → fosforila cadena ligera miosina → contracción

Estriado: Ca²⁺ + Troponina C → desplaza tropomiosina → expone sitios actina-miosina

Liso: sin sarcómeros, involuntario (ANS + hormonas), tónico. Estriado: sarcómeros organizados, voluntario, fásico.

💡 Antimicrobianos — Subunidad ribosomal

"Buy AT 30, CELL at 50"

💡 Plexo Braquial — "Robert Taylor Drinks Cold Beer"

Roots → Trunks → Divisions → Cords → Branches

Terminales: Musculocutáneo (bíceps) → Axilar (deltoides) → Radial (extensores, wrist drop) → Mediano (tenar) → Ulnar (garra)

Erb-Duchenne (C5-C6): "waiter's tip". Klumpke (C8-T1): garra + Horner. Radial = surco espiral del húmero → fractura → wrist drop.

💡 Síntesis de Colágeno

Intra: Traducción → Hidroxilación (Vit C!) → Glicosilación → Triple hélice

Extra: Escisión propéptidos → Tropocolágeno → Cross-linking (lisil oxidasa, Cu²⁺)

Sin Vit C → escorbuto. Sin Cu²⁺ → Menkes. Defecto Col I → OI (fracturas, escleras azules). Defecto Col III → Ehlers-Danlos vascular.

💡 Regulación del Calcio

PTH = "Phosphate Trashing Hormone" → ↑Ca²⁺, ↓PO₄

PTH → hueso: resorción (RANKL) → riñón: reabsorbe Ca²⁺, pierde PO₄, activa 1α-hidroxilasa → ↑Calcitriol → intestino: absorbe Ca²⁺+PO₄

Calcitonina = "tono down" → inhibe osteoclastos, de células C parafoliculares. Bifosfonatos imitan calcitonina.

💡 Tumores Óseos — Edad + Localización + Imagen Rx

<20a: Osteosarcoma (metáfisis, "sunburst", ↑FA, Codman) • Ewing (diáfisis, "piel de cebolla", t(11;22))

20-40a: T. células gigantes (epífisis, "burbuja de jabón")

>40a: Metástasis >>> primario (mama, próstata, pulmón, riñón, tiroides)

Osteocondroma = benigno #1. Condrosarcoma = maligno cartilaginoso, >40a, pelvis. Osteoma osteoide = dolor nocturno mejora con aspirina.

💡 Osteoporosis — Diagnóstico y Tratamiento

DEXA: T ≤ -2.5 = osteoporosis • -1 a -2.5 = osteopenia • > -1 = normal

1ra línea: Bifosfonatos (alendronato, zoledronato) → inhiben osteoclastos → EA: osteonecrosis mandibular, fractura atípica, esofagitis

Alternativas: Denosumab (anti-RANKL), Teriparatida (PTH, anabólico), Raloxifeno (SERM, riesgo TVP).

SUMATIVO 03 — Lunes de Semana 7

Después del examen: inicio inmediato de repaso integral para NBME y finales.

💡 AINEs — COX-1 vs COX-2

No selectivos (ibuprofeno, naproxeno): gastropatía, nefrotoxicidad, antiplaquetario

COX-2 selectivos (celecoxib): ↓GI pero ↑riesgo cardiovascular

Aspirina: irreversible sobre COX-1 plaquetaria → efecto 7-10 días. Única AINE irreversible.

💡 Gota vs Pseudogota — Cristales

Gota: Urato monosódico = aguja, birrefringencia negativa, 1er MTF ("podagra")

Pseudogota: Pirofosfato Ca²⁺ = romboide, birrefringencia positiva, rodilla

Aguda: colchicina + AINEs + corticoides. Crónica: alopurinol/febuxostat. NUNCA alopurinol en crisis. Lesch-Nyhan: HGPRT → hiperuricemia + automutilación.

💡 Osificación — Endocondral vs Intramembranosa

Endocondral: Cartílago → hueso. Huesos largos, vértebras. Placa epifisiaria (reserva→proliferación→hipertrofia→calcificación→osificación)

Intramembranosa: Mesénquima → hueso directo. Cráneo, clavícula, mandíbula

Acondroplasia = defecto osificación endocondral (FGFR3). Huesos intramembranosos no se afectan.
